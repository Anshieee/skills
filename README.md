# Skills

A home for reusable agent skills — instructions and workflows that get loaded into a
coding agent's context when a task matches them.

## Coming soon

**`review-writeup`** — the first skill in this repo. Not written yet.

Its intended shape is a hybrid: part review checklist (find the real problems, rank them,
don't nitpick for the sake of it) and part writeup (turn the findings into something a
teammate can read without needing the diff open side by side). Direct about what's broken,
fair about what isn't — no hedging, no padding.

## Layout

Nothing here yet. Skills will live in their own directories, each with a `SKILL.md`.
