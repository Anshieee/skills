# Grill question format

Load this file when a grill round starts. Skip it for any other task.

Use one heading per question, in order, with these subheads and one or two short bullets each.

## Q1. Short title

**What this is about**
The decision in one or two lines.

**If you say yes**
What happens next.

**If you say hold**
What happens instead, and what is still possible.

**What I need from you**
The exact input or choice.

**Recommendation**
One line, with the reason.

## Rules

- Plain markdown only: headings, bold, and bullet lists.
- The bans in `SKILL.md` apply here too. That file is the single source for them.
- One question per heading, numbered across the round.
- Keep each bullet short enough to scan.
